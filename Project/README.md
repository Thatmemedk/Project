# Jobbannons-analys för AI-utvecklare

## Projektstatus

Projektet är påbörjat. Första steget är att testa anslutningen till JobTech API och hämta jobbannonser.

## Plan

1. Hämta jobbannonser från JobTech API
2. Spara relevanta data i CSV
3. Analysera efterfrågade teknologier
4. Implementera klasser och arv
5. Lägga till visualisering
6. Dokumentera resultat, branschanalys, certifikat och reflektion
7. Publicera projektet på GitHub

## Filer

- `jobbannons_analys.ipynb` – projektets Jupyter Notebook
- `jobbdata.csv` – skapas när dataexporten implementeras
- `README.md` – projektets dokumentation

## AI-användning

AI används som stöd för idéer, förklaringar och felsökning. All kod som lämnas in ska förstås och kunna förklaras av studenten.
